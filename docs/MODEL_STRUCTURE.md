# Model structure

Generated by `tools/model_inventory.py` from the `.slx` files themselves — a
Simulink model is a zip package whose block diagram is XML, so this table is
read out of the model rather than typed by hand. Re-run the tool after any
model change; `--check` fails when this file is stale.

The algorithm is not only in the block wiring: each model carries MATLAB
Function blocks whose source is embedded in the package. Their code is
extracted verbatim into `src/model_code/<model>/` by `tools/extract_model_code.py`,
so it can be read and diffed outside MATLAB.
